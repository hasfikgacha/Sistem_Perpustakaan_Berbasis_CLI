# Sistem_Perpustakaan_Berbasis_CLI
Program di atas adalah projek UAS Praktikum Pemrograman Kelas A yang dikerjakan oleh kelompok 5, dengan anggota dan pembagian sebagai berikut.
1. Hasanul Fikri ( 260810701100013 )
2. Kayla Zuhra ( 260810701100033 )
3. Khalisah ( 260810701100021 )
4. Rajwa Ken Venona ( 260810701100028 )

Program ini nantinya akan beroperasi dengan menggunakan CLI sebagai basis interaksinya.

Fitur-Fitur yang akan ditambahkan:
1. Login untuk Admin dan User
2. Membuat user baru
3. User, dengan fitur dan kemampuan sebagai berikut.
   1. Melihat katalog buku
   2. Mencari buku tertentu melalui ocaid, judul buku, author, dan parameter lainnya.
   3. Meminjam buku
   4. Nencatat peminjaman
   5. Melihat History/log peminjaman buku
   6. Mengembalikan buku yang sudah dipinjam
4. Admin, dengan fitur dan kemampuan sebagai berikut.
   1. Melihat katalog buku
   2. Menambahkan buku baru ke dalam katalog
   3. Mengubah data buku dalam katalog
   4. Menghapus data buku dalam katalog
   5. Melihat History/log peminjaman buku
5. Sorting katalog buku berdasarkan judul buku, author, ocaid, dsb., dengan metode sbb.
   1. Bubble Sort
   2. Selection Sort
   3. Insertion Sort
  
Fitur-fitur lainnya akan segera direncanakan
